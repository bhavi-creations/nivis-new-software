LIVE DEPLOYMENT:
No live host or connected deployment access was supplied, so live deployment has
NOT been performed. This ZIP targets an existing copy of this billing application.
1. Back up the matching live files and the company_settings row.
2. Extract the ZIP into the application's existing directory, preserving paths.
   Do not put it inside an extra nested folder. No database credentials are included.
3. Run from the application directory, if hosting offers a terminal:
     php database/update_business_profile.php
   Otherwise save the supplied name/address/email/phone through Settings. The
   quotation stationery itself uses config/business_profile.php immediately.
4. Reload a quotation and an invoice; use Ctrl+F5 if an older page remains open.
5. Download a short quotation and a long quotation with many rows. Check all
   rows/totals, repeated table headings, page numbers and From details. Repeat on
   a mobile-width screen. Test the invoice's distinct green layout and payment totals.
